# AI News Agent

A browser-based AI Morning News Briefing Agent.

## Version

V1 — Initial Prototype

## What it does

The AI News Agent is designed to eventually:

- Collect the latest global news
- Identify important/trending stories
- Summarise the news using AI
- Create a personalised morning briefing
- Deliver the briefing to your phone

## Current Version

V1 is a simple browser prototype.

The current version uses demonstration news stories while we build the core interface.

## Planned Development

## Security

API keys and other secrets must never be placed directly in the website code or committed to GitHub.

When we introduce APIs, secret keys will be stored securely using environment variables and a backend.
